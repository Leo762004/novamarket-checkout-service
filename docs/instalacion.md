\# Guía de instalación



\## Propósito



Esta guía describe el proceso básico para instalar y preparar el servicio Checkout Service de NovaMarket, permitiendo que los miembros del equipo trabajen sobre una base común y documentada.



\## Requisitos previos



\- Tener Git instalado en el equipo.

\- Contar con acceso al repositorio del proyecto.

\- Disponer de permisos para crear ramas y Pull Requests.

\- Tener un entorno local configurado para trabajar con la documentación del servicio.



\## Preparación del entorno



1\. Clonar el repositorio de NovaMarket Checkout Service.

2\. Acceder a la carpeta del proyecto.

3\. Crear una rama de trabajo para realizar modificaciones.

4\. Verificar que la estructura del proyecto y la carpeta de documentación estén disponibles.



\## Validación funcional



\- Confirmar que el repositorio se descargó correctamente.

\- Verificar que los archivos de documentación sean accesibles.

\- Comprobar que los cambios realizados puedan visualizarse en GitHub mediante un Pull Request.

\- Revisar que la documentación sea clara y comprensible para otros integrantes del equipo.



\## Error común que debe evitarse



No se deben realizar cambios directamente sobre la rama main. Todas las modificaciones deben pasar por un proceso de revisión mediante Pull Request para garantizar la trazabilidad y el control de cambios.
